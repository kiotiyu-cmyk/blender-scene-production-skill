# 结构与画风

## 几何方法选择

| 构造需求 | 通常适合的实现 | 需核对的关系 |
| --- | --- | --- |
| 整体壁体的贯穿开口 | 主体与 Boolean 切割体 | 实际厚度、穿透、边缘清理；独立石砌门框按构件设计 |
| 规则楼梯、柱列、窗格 | Array 或共享实例 | 起终点、方向、步高、步深、数量、平台归属 |
| 连续栏杆、管道、藤蔓 | 曲线与截面，或明确焊接拓扑 | 转折、截面、端点、局部框架与扭转 |
| 地形和岩体主轮廓 | 可编辑网格、雕刻或有足够拓扑的位移 | 承托、坡度、接合及通行关系 |
| 群落与场景散布 | 实例或 Geometry Nodes | 生长/分布逻辑、密度层次、重复感和运行预算 |
| 可控机械/形变 | 约束、变形修改器、骨骼等 | 轴、支点、接口与运动范围 |
| 有因果动态的水、布、碎片 | 适当模拟或可验证的艺术控制 | 宏观运动、接触、缓存和循环稳定性 |

选择最简单且保留所需控制的方法，不把任何一项当所有场景的强制方案。Join、父子关系和重叠不证明连续表面已融合；平滑法线也不证明真实边缘转折已建立。远景或固定画面允许适当简化，但不得破坏可见轮廓、接触、阴影或倒影。

## 表面响应

先确定基材、涂层、物理尺度与方向，再做颜色、粗糙度、法线/Bump、位移和局部变化。颜色图与数据图的色彩空间按实际内容设置；法线强度与凹凸尺度避免重复叠加。导入模型的高面数或高分辨率贴图不能自动统一整体画风。

写实表面：在中性光和掠射反光下查看高光宽度、纹理尺度与湿干区别。污迹按积水、流向、接触、裂缝或暴露位置组织，不用同一全局噪声同步驱动所有通道。

手绘表面：以母图的轮廓、色块、笔触尺度、明暗简化与边缘语言为目标，协调几何、贴图、法线、光照和合成。先验证一块代表材质在最终距离下是否成立。卡通分色或黑描边是候选技法，不是“手绘”或“水粉”必选项。清楚区分二维绘制效果与已经在三维/运动中验证的画风。

## 水与湿润

薄湿膜主要改变表面反光与基材；有可见深度的池水需水线、厚度与容器接触。水位、出水口、瀑布起落和承接水体统一坐标与尺度。大波形由几何/模拟控制，小波纹由材质控制，避免同尺度双重位移。

体积吸收随厚度和场景尺度变化。先核对水下对象、掠射倒影、池壁接触与浅深差异，再调整颜色；黑水或玻璃板感可能源于几何、吸收、反射环境、反弹次数或曝光，不能只猜一个参数。

自然溢流先画清水体关系：泉源/容器 → 满水位 → 低缺口 → 连续落水 → 承接池。参考要求整片瀑布时，不能无依据增加地砖上的直槽或拆成两根水管；薄层、水丝、泡沫和水雾共同建立体积。池边用水线、湿石、浅水和少量植被形成尺度过渡，避免整圈等宽石边或规则的装饰环。

植物根据水、土、裂缝、受光和重力形成疏密群落，避免沿杯沿等距悬挂。破损要改变真实边缘和厚度；仅加斑驳贴图不能修正过分光滑的轮廓。

## 光照与氛围

从参考受光面、阴影、窗洞和实际灯具推断来源，记录有歧义的假设。主光与环境填充建立灰度层次后，再加入有用途的反弹、灯具、雾或合成。外景与室内分别选择适当方案，不强制每场景起手 Sun 或 HDRI。

雾服务距离和光束；色光服务实际来源与叙事。修错轮廓、破碎接合或硬直边缘时，先在中性材质与清晰光照中暴露问题，再回生产光。若要判断是否“只差渲染”，分别比较几何、材质、光照与采样变量，不同时改变后归因。


背景云图、环境照明与主光是三件事：背景里画有光束，不等于场景里已经有相同方向的照明和阴影。让主体受光面、明暗交界、投影方向及云的暖边互相对应；保持适量填充，不把所有表面照成同一灰度。

需要云遮住地形边缘时，用有纵深和不均匀疏密的云层安排遮挡；按效果选择体积、分层云片或其他可验证实现，不强制全场体积。环绕时检查云片朝向、视差、接缝和背景亮度，避免均匀一圈棉花或用雾掩盖未修好的结构。
